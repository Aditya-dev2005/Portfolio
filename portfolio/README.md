# Aditya Chaturvedi — Portfolio

A modern, premium developer portfolio built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Prerequisites

- Node.js v18+ → https://nodejs.org
- npm v9+

Check: `node --version` and `npm --version`

---

## Run Locally

### Step 1 — Go into the folder
```bash
cd portfolio
```

### Step 2 — Install dependencies
```bash
npm install
```

### Step 3 — Start dev server
```bash
npm run dev
```

### Step 4 — Open browser
Visit: http://localhost:3000

---

## Build for Production
```bash
npm run build
npm start
```

---

## Deploy to Vercel (Free)

### Option A — CLI
```bash
npm install -g vercel
vercel
```

### Option B — GitHub
1. Push to GitHub
2. Import repo at vercel.com
3. Click Deploy
